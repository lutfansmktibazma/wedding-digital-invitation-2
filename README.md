# The Wedding of Allesya & Haikal 💍

Undangan pernikahan digital berbasis web interaktif dengan pengalaman scroll sinematik (*scroll-driven cinematic storytelling*). 

Didesain khusus dengan perpaduan palet warna klasik maroon, ivory, serta sentuhan aksen emas elegan, menghadirkan nuansa pesta perkahwinan yang agung dan berkelas.

---

## ✨ Fitur Utama

- **Interactive Curtain Opening:** Tirai maroon membuka secara otomatis dan dinamis mengikuti sentuhan scroll pertama pengunjung.
- **Cinematic Scene Progression:** Animasi zoom, pergerakan kamera halus (lerp), dan peralihan teks antar adegan yang proporsional.
- **Countdown Timer Otomatis:** Penghitung mundur waktu menuju hari bahagia pernikahan (Hari, Jam, Minit, Saat).
- **Integrasi Lokasi & Peta:** Tombol navigasi langsung ke Google Maps & Waze untuk mempermudah tamu menuju lokasi acara.
- **Background Music Player:** Musik latar syahdu dengan tombol kontrol audio (mute/unmute) mengambang.
- **Tipografi Eksklusif:** Kombinasi harmonis antara font klasik *Cormorant Garamond*, *Cormorant SC*, *Playfair Display*, serta kaligrafi Arab *Lateef*.
- **Mobile-First Responsive Design:** Dioptimalkan secara presisi untuk kenyamanan akses pada perangkat smartphone.

## 🛠️ Teknologi

- **HTML5 & CSS3:** Custom responsive layout, radial glow lighting, dan animasi CSS native.
